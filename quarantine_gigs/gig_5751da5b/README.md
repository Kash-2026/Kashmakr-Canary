# SEO Metadata Engine

This engine generates SEO-friendly titles and meta descriptions based on a page topic and keyword. It enforces pixel and character limits, checks keyword placement, and scores click-through potential.

## Usage

1. Instantiate the `SEOMetadataEngine` with a page topic and keyword.
2. Use `generate_title` and `generate_description` to create metadata.
3. Use `score_click_through_potential` to evaluate the metadata.
