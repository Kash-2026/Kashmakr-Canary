# Agent Planner

## Usage
1. Create an instance of `AgentPlanner`.
2. Add tasks with `add_task(name, dependencies)`.
3. Build the execution order with `build_execution_order()`.
4. Execute tasks with `execute_task(name)`.
5. Retry failed tasks with `retry_failed_tasks()`.

## Installation
No installation required. This module uses only the Python standard library.
