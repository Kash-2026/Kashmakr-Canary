# Lead Magnet Planner

## Usage
1. Install dependencies: `pip install -r requirements.txt`
2. Run tests: `python -m pytest test_lead_magnet_engine.py`

## Functions
- `generate_lead_magnet_concepts(audience, pain_point)`: Generates a lead magnet concept.
- `get_format_delivery_choices()`: Returns a random format/delivery choice.
- `calculate_conversion_likelihood(audience, pain_point)`: Calculates a conversion-likelihood score.
