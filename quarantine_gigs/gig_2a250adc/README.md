## Pricing Card Component

A React component to display pricing information with a monthly/annual toggle.

### Props
- `monthlyPrice` (number): Monthly price.
- `annualPrice` (number): Annual price.
- `discountPct` (number): Discount percentage for annual plan.
- `featureList` (array of strings): List of features.

### Usage
Import and use the `PricingCard` component in your React application.

### Testing
Run `npm test` to execute tests.
