# Business Model Canvas Engine

This engine fills a nine-block business model canvas from a venture specification, checks the completeness of required blocks, and computes a coherence score.

## Usage

1. Create an instance of `BusinessModelCanvas`.
2. Fill the canvas with venture specifications using `fill_canvas`.
3. Check the completeness of the canvas using `check_completeness`.
4. Compute the coherence score using `compute_coherence_score`.
